# 部屋予約管理システム

直感的な操作が可能な部屋予約管理アプリケーション

## 特徴

- **グリッド表示**: X軸に時間（5分単位）、Y軸に部屋番号で見やすく表示
- **カスタマイズ可能な設定**: 部屋数、始業時間、終業時間を自由に設定
- **直感的な操作**: クリックで予約の作成・削除が可能
- **データ永続化**: ブラウザのローカルストレージに自動保存

## 使い方

### 開発環境のセットアップ

```bash
# 依存パッケージのインストール
npm install

# 開発サーバーの起動
npm run dev

# ビルド
npm run build
```

### アプリケーションの使い方

1. **設定の変更**
   - 右上の「⚙️ 設定」ボタンをクリック
   - 部屋数、始業時間、終業時間を入力
   - 「保存」をクリック

2. **予約の作成**
   - グリッド上の空いているセル（時間枠）をクリック
   - タイトルと時間帯を入力
   - 「作成」をクリック

3. **予約の削除**
   - 既存の予約（青色のセル）をクリック
   - 確認ダイアログで「OK」をクリック

## 技術スタック

- React 18
- TypeScript
- Vite
- CSS Grid Layout

## デフォルト設定

- 部屋数: 5
- 始業時間: 09:00
- 終業時間: 18:00
- 時間間隔: 5分
